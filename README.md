# 하폐수처리장 360° 위험성평가

**`index.html`을 크롬 또는 엣지로 열면 바로 사용할 수 있습니다. 설치나 서버가 필요하지 않습니다.**

GitHub Pages로 배포된 경우 공유받은 사이트 주소로 접속해도 사용할 수 있습니다. 사이트에서 입력하거나 선택한 사진은 해당 브라우저에서 처리되며 GitHub로 자동 업로드되지 않습니다. 서로 다른 사용자의 입력 내용은 자동 공유되지 않습니다.

공개 저장소에는 앱과 예시 사진, `결과/01_구역관찰.md`, `결과/02_현장위험성평가표.md`, `결과/pins.json`이 포함됩니다. 평가 자료는 사진 기반 잠정평가이며 실제 현장 확인·최종 결재를 대신하지 않습니다. `pins.json`을 사용할 때는 먼저 [사진 바꾸기]에서 `현장사진_예시.png`를 선택한 다음 JSON을 붙여넣으세요.

## 1. 처음 시작하기

1. `index.html`과 `site.jpg`를 같은 폴더에 둡니다.
2. `index.html`을 더블클릭합니다. 다른 프로그램으로 열리면 마우스 오른쪽 버튼 → 연결 프로그램 → Chrome 또는 Microsoft Edge를 선택합니다.
3. 기본 사진은 **실습용 그림**입니다. 실제 평가에는 [사진 바꾸기]로 현장 JPG·PNG·WebP 사진을 선택합니다. 원본 사진은 변경되지 않습니다.
4. 오른쪽 위 점검일을 확인합니다.

이 앱은 평면 사진을 세 장 이어서 보여줍니다. 원근 왜곡을 만드는 구면 뷰어가 아니며, 사진 양쪽 끝이 맞지 않으면 이음새가 보입니다. [360° 이어 보기]를 누르면 [끝에서 멈춤]으로 바뀝니다.

## 2. 사진 둘러보기

- 사진을 누른 채 좌우·위아래로 끌어 이동합니다.
- 마우스를 좌우 가장자리 8% 구간에 두면 천천히 이동합니다. 가운데 84%에서는 멈춥니다.
- 마우스가 밖으로 나간 뒤 2.5초가 지나면 느리게 자동 회전합니다. 핀을 편집하거나 위치를 찍는 동안에는 자동 이동이 멈춥니다.
- [−] [＋]로 1~3배 확대·축소합니다. [처음 시점]은 확대와 시점을 초기화합니다.
- 전체 파노라마 미니맵을 누르면 그곳으로 이동합니다. 노란 사각형은 현재 보이는 범위입니다.
- [움직임 줄이기]를 켜면 마우스 반응 이동·자동 회전·관성·이동 애니메이션을 멈춥니다.
- [표시 보기]는 핀의 설명 말풍선을 켜거나 끕니다. 핀 번호는 계속 보입니다.

## 3. 위험 핀 추가와 편집

1. [＋ 핀 추가]를 누른 뒤 사진의 위험 위치를 클릭합니다.
2. 오른쪽 ‘선택한 핀’에서 유형과 위험요인을 입력합니다.
3. 위험요인은 **‘[작업] 중 [누가] [무엇 때문에] [어떻게 다치는가]’** 형태로 씁니다.
4. 사진에 분명히 보이는 근거는 [확실], 가능성만 있는 근거는 [추정]으로 구분합니다. 사진만으로 알 수 없으면 ‘현장 확인 필요’를 유지합니다.
5. 빈도·강도와 **각 점수의 근거**를 입력합니다. 새 핀의 1×1은 입력 시작값이며, 안전하다는 판정이 아닙니다.
6. 개선대책은 **[제거] → [공학] → [관리] → [보호구]** 순서로 검토하여 분류를 붙입니다.
7. 법적 기준은 원문을 직접 확인한 경우에만 ‘법령명 제○조(제○항) (원문 확인)’으로 적습니다. 확인하지 못했다면 ‘확인 필요’로 남깁니다.

법적 근거 검토 순서: 산업안전보건법·시행규칙 → 산업안전보건기준에 관한 규칙 → 사업장 위험성평가에 관한 지침 → KOSHA GUIDE → 사업장 자체 기준.

앱은 법령 원문을 검색하거나 내용을 자동 검증하지 않습니다. 산소·가스 농도와 노출 빈도는 사진만으로 확정할 수 없습니다. **최종 판단과 결재는 사람이 합니다.**

### 위치만 고치는 다섯 가지 방법

| 방법 | 조작 |
|---|---|
| 사진에서 끌기 | 번호 핀을 누른 채 새 위치로 이동 |
| 미니맵에서 끌기 | 작은 핀 점을 누른 채 이동 |
| 숫자 입력 | ‘핀 위치’의 x·y에 0~100 입력 |
| 다시 찍기 | [📍 위치 다시 찍기] → 사진의 새 위치 클릭 |
| 방향키 | 핀 선택 후 방향키로 0.1% 이동, Shift와 함께 누르면 1% 이동 |

위치를 옮겨도 내용은 유지됩니다. x=0은 사진 왼쪽, x=100은 오른쪽, y=0은 위, y=100은 아래입니다. 입력칸에 커서가 있을 때는 방향키가 입력칸을 조작하므로 사진 영역을 눌러 포커스를 옮기세요. Esc는 핀 선택과 다시 찍기를 해제합니다.

핀을 선택하지 않은 상태에서 ← →는 시점 회전, ↑ ↓는 위아래 이동입니다. + −는 확대·축소입니다.

## 4. 위험도와 통계

위험도 = 빈도(1~5) × 강도(1~4).

| 위험도 | 수준 | 핀 테두리 |
|---|---|---|
| 1~3 | 무시 | 초록 |
| 4~6 | 미미 | 초록 |
| 8 | 경미 | 초록 |
| 9~10 | 상당한 수준 | 노랑 |
| 12~15 | 중대 | 주황 |
| 16~20 | 허용불가 | 빨강 |

정수 곱으로 나오지 않는 7·11·13·14·17·18·19점은 직접 입력하지 않습니다.

- **사진에 표시한 위험:** 전체 핀 수
- **허용불가·중대:** 위험도 12점 이상인 핀 수
- **점검 범주 누락:** 5개 점검 범주 중 핀이 없는 범주 수. ‘기타’는 범주 충족에 포함하지 않습니다.
- **기존 보고서 미반영:** 반영이 ‘없음’인 핀 수. ‘부분’은 제외합니다.

‘누락?’은 위험이 실제 있다는 판정이 아닙니다. 해당 점검 범주를 현장에서 확인하라는 표시입니다.

## 5. AI JSON 불러오기

[AI 결과(JSON) 붙여넣기]에 배열을 넣고 [추가] 또는 [기존 핀 지우고 바꾸기]를 누릅니다. **앱 자체는 AI에 사진을 전송하거나 분석 요청을 하지 않습니다.**

아래는 입력 형식 예시이며 실제 위험성평가 결과가 아닙니다.

```json
[
  {
    "x": 30,
    "y": 60,
    "유형": "추락",
    "위험요인": "현장 확인 후 작업·작업자·원인·부상 형태를 입력",
    "사진근거": "추정",
    "현장확인": "현장 확인 필요",
    "법적기준": "확인 필요",
    "빈도": 1,
    "빈도근거": "현장 확인 필요 · 임시 점수",
    "강도": 1,
    "강도근거": "현장 확인 필요 · 임시 점수",
    "개선대책": "[제거] 검토\n[공학] 검토\n[관리] 검토\n[보호구] 검토",
    "관리방법": "담당자·점검 주기·조치 기한 확인 필요",
    "보고서반영": "없음"
  }
]
```

- 앞뒤 설명 문장이나 코드 표시가 있어도 배열을 찾아 읽습니다.
- 모든 좌표가 0~1이면 비율로 판단하여 100을 곱합니다. 예: x=0.3 → 30%.
- 실제로 0~1% 지점을 뜻하거나 좌표 단위가 섞여 있다면 자동 판단이 맞지 않을 수 있습니다. **좌표 단위**에서 ‘퍼센트’ 또는 ‘비율’을 직접 고르세요. 한 배열의 좌표 단위는 통일해야 합니다.
- 비슷한 유형 이름은 표준 유형에 맞춥니다. 알 수 없는 이름은 ‘기타’로 들어가므로 검토하세요.
- 좌표가 없거나 범위를 벗어나거나 점수가 정수가 아니면 오류 이유를 보여줍니다. 오류 시 기존 핀은 유지됩니다.
- 한 작업은 최대 1,000개 핀을 지원합니다.

## 6. 저장·복원·내보내기

- **자동 저장:** 입력할 때마다 같은 브라우저의 localStorage에 저장합니다. 브라우저·프로필·HTML 경로가 달라지면 저장 자료가 보이지 않을 수 있습니다. 시크릿 모드 종료나 브라우저 데이터 삭제 시 사라질 수 있습니다.
- **작업 저장:** 사진 정보·핀·설정이 포함된 JSON을 내려받습니다. 바꾼 사진은 파일 안에 함께 저장됩니다. 기본 사진은 `site.jpg` 경로를 사용하므로 작업을 다른 PC로 옮길 때 `index.html`, `site.jpg`, 작업 JSON을 함께 옮기세요.
- **작업 불러오기:** 이 앱에서 저장한 작업 JSON을 선택합니다. 현재 작업을 바꾸기 전에 확인창이 뜹니다.
- **위험성평가표 CSV:** 위험도 높은 순서로 전체 입력 내용을 내려받습니다. UTF-8 BOM을 넣어 엑셀의 한글 깨짐을 줄입니다. 엑셀 수식으로 실행될 수 있는 시작 문자는 문자로 처리합니다.
- **인쇄(게시용):** A4 가로, 번호가 표시된 전체 사진과 위험도 높은 순서의 표가 나옵니다. 인쇄 창에서 용지와 방향을 확인하세요.

내려받은 파일은 **이 폴더 안의 `결과` 폴더**로 저장하거나 옮기세요. 브라우저 보안상 앱이 다운로드 폴더를 강제로 지정할 수는 없습니다.

사진이 커서 브라우저 저장 용량을 넘으면 ‘자동 저장 실패’가 표시됩니다. 이때는 닫기 전에 반드시 **[작업 저장]**으로 파일을 보관하세요.

## 7. 삭제와 사진 변경

- [이 핀 삭제]는 선택한 핀 한 개를 지웁니다.
- 두 곳의 [핀 모두 제거]는 같은 기능입니다. 삭제 전 개수와 되돌릴 수 없다는 안내가 나옵니다. 필요한 자료는 먼저 [작업 저장]으로 보관하세요.
- 사진을 바꿀 때는 위치가 맞지 않게 되는 기존 핀을 확인 후 삭제합니다.
- 원본 `site.jpg`, `현장사진_예시.png`는 수정하지 않습니다.

## 8. 파일 구성과 점검 기록

- `index.html`: 앱 본체. HTML·CSS·JavaScript가 한 파일에 들어 있습니다.
- `site.jpg`: 기본 실습용 사진.
- `현장사진_예시.png`: 보존한 원본 사진.
- `결과/01_구역관찰.md`: 예시 사진의 구역별 관찰.
- `결과/02_현장위험성평가표.md`: 예시 사진의 잠정 위험성평가.
- `결과/pins.json`: 앱에 붙여넣을 수 있는 예시 핀 9개.
- 로컬 작업 폴더의 `결과/기능점검.md`와 `결과/검증결과.json`: 개발 점검 기록. 공개 배포에서는 제외합니다.

외부 라이브러리·CDN·웹 글꼴·서버를 사용하지 않습니다. 앱에는 외부로 데이터를 보내는 코드가 없으며, 외부 연결을 차단하는 보안 정책도 적용했습니다.
