# 01. 구역별 현장 관찰

대상: `현장사진_예시.png` · 원본 2172×724픽셀 · 관찰일: 2026-10-20

사진을 왼쪽부터 5개 구역으로 나눠 관찰했다. 좌표는 **사진 전체의 왼쪽 위 (0,0) ~ 오른쪽 아래 (100,100)** 기준이며, 관찰 대상의 대략적인 중심 위치다. 구역 경계에 걸친 대상은 중심이 있는 구역에 배정했다.

**[확실]은 사진에서 보이는 상태에 대한 표시이며, 법령 위반이나 사고 발생을 확정한다는 뜻이 아니다.** 작업 종류·액체 성분·설비 가동 여부·안전조치 이행 여부는 사진만으로 확정할 수 없어 [추정] 또는 ‘현장 확인 필요’로 기록했다. 점수는 매기지 않았다.

## 구역마다 적용한 6개 점검 관점

‘미관찰’은 사진에서 식별되지 않았다는 뜻이며, 현장에 없다는 판정이 아니다.

| 구역 | ① 밀폐공간 | ② 추락 | ③ 질식·유해가스·화학물질 | ④ 시설물·개구부 | ⑤ 정비·청소 | ⑥ 기타 |
|---|---|---|---|---|---|---|
| 1구역 | 탱크가 보이나 출입구·출입 행위는 식별 불가. 측정기·환기·감시인·출입금지 표지는 식별 불가. | 탱크 상부 난간과 기대어 놓인 사다리 관찰. 사다리 고정·승하차 안전은 현장 확인 필요. | 탱크 주변 가스·산소 농도는 사진으로 판단 불가. 포장물 내용물은 확인 불가. | 단차와 파손된 턱 U01 확인. | 배관은 보이나 정비 행위·회전체 접촉·인양 작업은 확인 불가. | 자재 적재 상태 관찰. 통로 폭·소화기 접근성은 현장 확인 필요. |
| 2구역 | 개구부 U02 확인. 연결 공간의 용도·밀폐공간 해당 여부와 출입 시 측정·환기·감시·표지는 현장 확인 필요. 사진에서 출입 행위는 미관찰. | 열린 바닥 개구부 U02, 사다리 하단 관찰. 깊이·안전조치는 현장 확인 필요. | 개구부 내부의 황화수소·산소결핍 여부는 사진으로 판단 불가. | 개구부 둘레에 사진상 차단시설이 보이지 않음. | 호스·밸브 관찰. 세척·이송 작업 여부와 설비 가동 여부는 확인 불가. | 통로를 가로지르는 호스 U03 확인. |
| 3구역 | 수조·구조물 아래 공간 관찰. 내부 출입·밀폐공간 해당 여부와 측정·환기·감시·표지는 현장 확인 필요. | 전면 일부 가장자리 U04 관찰. 접근 가능성·낙차는 현장 확인 필요. | 수조 주변 유해가스·산소 농도는 사진으로 판단 불가. | 콘크리트 가장자리·손상 U04·U05 관찰. | 배관·호스 관찰. 실제 정비·청소·인양 작업은 확인 불가. | 호스 U03이 이어짐. 손상부 접근 시 걸림·접촉 가능성은 추정. |
| 4구역 | 뒤쪽 탱크 관찰. 출입 행위·개방된 출입구, 측정기·환기·감시인·출입금지 표지는 식별 불가. | 탱크 고정식 사다리·상부 난간 관찰. 부착·손상 상태는 현장 확인 필요. | 용기·드럼과 바닥 액체 U06·U07 확인. 화학물질명·농도·누출원·보호구 필요 수준은 확인 불가. | 용기 주변 바닥 상태 관찰. 안전한 이동 경로는 현장 확인 필요. | 펌프·모터 관찰. 회전체의 실제 노출, 방호장치 적정성·가동 상태는 현장 확인 필요. 인양 작업은 미관찰. | 젖은 바닥 U06, 가로로 놓인 열린 드럼 U07 확인. |
| 5구역 | 직접적인 공간 출입 행위는 미관찰. 주변 공간의 출입 관리·농도 측정·환기·감시·표지는 사진만으로 확인 불가. | 기둥 주변 단차 관찰. 높은 곳에서 작업하는 사람은 미관찰. | 젖은 구간이 이어짐. 액체의 화학적 위험성·작업자 노출 및 보호구 적정성은 현장 확인 필요. | 제어반 문 개방과 주변 바닥 상태 관찰. | 작업자·펌프·열린 제어반 U08 확인. 가동·충전·차단·잠금 여부는 확인 불가. 인양 작업은 미관찰. | 바닥의 선 U09, 전선 릴·통·공구함류 관찰. 이동 동선과 정리정돈은 현장 확인 필요. |

## 집계 기준

- U01~U09는 사진에서 식별되는 **불안전 상태 또는 추가 검토가 필요한 상태**를 대상으로 부여한 번호다. 법령 위반 확정 건수가 아니다.
- 같은 호스, 같은 연속된 젖은 바닥을 여러 구역에서 다시 보더라도 한 건으로 집계했다.
- 사다리 고정 미실시, 감시인 부재, 보호구 미착용, 유해가스 존재, 전원 미차단, 회전체 방호 미설치처럼 사진만으로 확정할 수 없는 항목은 총 개수에 추가하지 않았다.
- **확정할 수 있는 불안전한 행동은 0건**이다. 사람의 자세만으로 불안전 행동을 단정하지 않았다.

**찾은 불안전 요소 총 9개(사진상 상태·검토 대상 U01~U09, 중복 제외).**
